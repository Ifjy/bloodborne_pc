  血源诅咒 PC(Windows 移植版)按键说明
  版本: 0.51 windows-port · 更新: 2026-10-11(按亚版实测修正)
  键鼠和手柄可以同时使用,随时切换
════════════════════════════════════════════════════════════════════

  一句话上手:左键砍、右键枪、Shift 闪、空格摸、Q 喝血、C 锁定

  本机是亚版(CUSA03023),✕/○ 和欧版相反(已实测):
    ✕ = 闪避翻滚(长按冲刺)· 菜单取消 → 左Shift
    ○ = 互动(开门/拾取/对话)· 菜单确认 → 空格

【移动 / 视角】────────────────────────────
  W / A / S / D      走路(前后左右)
  方向键 ↑↓←→        转视角
  鼠标移动           转视角(先进游戏画面点一下捕获鼠标)
  F1                 释放鼠标(切出去干别的事)
  C                  锁定 / 解锁敌人

【战斗】──────────────────────────────────
  鼠标左键 或 3       轻攻击
  鼠标右键 或 R       枪击(左手武器)
  F 或 鼠标侧键前     重攻击(按住 = 蓄力)
  1 或 鼠标侧键后     武器变形(攻击中按 = 变形攻击)
  左Shift            闪避翻滚(长按 = 冲刺跑)
  Q                  直接喝血瓶(不占快捷栏)

【道具 / 互动】────────────────────────────
  空格               互动(开门、拾取、对话)
  E                  使用当前快捷栏道具(可把血瓶放这里)
  K 或 滚轮 ↓        切换快捷栏道具
  I 或 滚轮 ↑        造血子弹(+5 发,消耗自己 HP!战斗中慎按)
  J / L              切换左手 / 右手武器

【菜单怎么按】────────────────────────────
  回车               打开暂停菜单(Options)
  空格 / 左Shift      确认 / 取消(亚版习惯,和欧版相反)
  I / K              列表上下
  J / L              分类左右(手持物/装备里换类别)
  1 / 3              大标签页左右(手持物 ↔ 装备 ↔ 系统)
  Tab                手势菜单(触摸板左半)
  (方向键 ←→ 是视角,在菜单里没反应,属正常)

【系统】──────────────────────────────────
  Insert             移植设置菜单(画质/超分/全屏/特效/跳过片头)
  Backspace          个人效果菜单(触摸板右半,少用)
  Z                  L3(基本用不到)

【鼠标详情】────────────────────────────────
  · 进入游戏后在画面上"点一下" → 鼠标被捕获开始转视角
    (那一下点击不会当成攻击,放心点)
  · 捕获后: 左键=轻攻击 · 右键=枪击 · 中键=锁定
    侧键前=重攻击 · 侧键后=武器变形 · 滚轮=十字键上/下
  · F1 或切出窗口 → 释放鼠标
  · 转视角速度: bbport.ini 里 mouse_sensitivity=(0.05~20,现设 2)

【画面/全屏(已配好)】──────────────────────
  · 全屏启动: bbport.ini fullscreen=1(游戏内 Insert 菜单也能改)
  · 输出分辨率: output_res=1920x1080(FSR3 超分,全屏铺满屏幕)

【手柄】──────────────────────────────────
  直接支持;L3/R3 失灵的老问题 → 用 Steam 里添加的
  "Bloodborne PC.exe" 启动即可(Steam Input 补全按键)

【自定义键位(bbport.ini,改完重启游戏)】─────
  格式: key.动作=键名  (多个键逗号隔开,最多 4 个)
  例:   key.circle=space        空格=○
        key.r1=3,Mouse Left     3 和左键都=轻攻击
  键盘键名(小写): a~z 0~9 · space · return · tab · backspace
    · up/down/left/right
  ⚠ 多词键名中间必须有空格: left shift / right shift / left ctrl
    (写成 leftshift 会解析失败,这个动作就整行没有按键!)
  鼠标键名: Mouse Left/Right/Middle · Mouse X1(侧键前) · Mouse X2(侧键后)
    · Wheel Up / Wheel Down
  动作名: cross circle square triangle l1 r1 l2 r2 l3 r3 options
    touchpad up down left right move_* look_*
  手柄: pad.动作=SDL手柄键名(south east west north leftshoulder...)

【本机已做的自定义(亚版实测有效)】──────────
  key.cross=left shift   左Shift=✕(闪避/冲刺/菜单取消)
  key.circle=space       空格=○(互动/菜单确认)
  mouse_sensitivity=2    鼠标视角 2 倍速
  fullscreen=1           全屏启动
